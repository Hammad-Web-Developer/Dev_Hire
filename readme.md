Job Application Tracking System :-

Main features
1. Authentication
- Candidates, recruiters, and administrators.
- JWT authentication and role-based authorization.
2. Job management
- Recruiters create and publish job listings.
- Candidates search and filter jobs by location, salary, skills, and category.
3. Application system
- Candidates apply for jobs and upload resumes.
- Prevent duplicate applications.
- Track application status.
4. Recruitment pipeline
- Recruiters move candidates through:
  - Applied
  - Shortlisted
  - Interview
  - Selected
  - Rejected
5. Interview scheduling
- Schedule interviews.
- Set dates and times.
- Notify candidates.
6. Analytics
- Number of applicants per job.
- Application conversion rates.
- Recruitment statistics.
